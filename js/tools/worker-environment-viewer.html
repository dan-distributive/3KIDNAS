DCP · discover-worker-environment

Worker environment capability matrix

Deploy a small read-only probe to real DCP workers and watch the matrix fill in as results arrive.

Deploy

Runs entirely in this browser tab via dcp-client -- no server, no upload. Only checks whether an API/module exists; never reads real files, env vars, or calls out to other hosts.

On by default -- without it, the scheduler may hand several/all slices to the same worker, and this tool exists specifically to sample distinct workers.
On by default -- WebGPU is opt-in per job, not ambient: without declaring `job.requirements.environment = {webgpu: true}`, DCP has no reason to enable WebGPU in the sandbox at all, regardless of the worker's real hardware. This is why earlier runs found nothing.
